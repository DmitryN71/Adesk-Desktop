# Adesk Desktop

Десктопный клиент для сервиса финансового учёта [adesk.ru](https://adesk.ru). Нативное Windows-приложение с поддержкой push-уведомлений, системного трея и глобальных горячих клавиш.

## Возможности

- **Нативные уведомления** — мгновенные Windows toast-уведомления о поступлениях, расходах, плановых платежах и обязательствах
- **Системный трей** — приложение работает в фоне и всегда доступно из области уведомлений
- **Глобальная горячая клавиша** — настраиваемый шорткат для быстрого вызова окна
- **Оповещение о низком балансе** — настраиваемый порог для предупреждений
- **Мультиязычность** — русский и английский интерфейс с автоопределением системной локали
- **Запуск при старте Windows** — опциональный автозапуск в свёрнутом режиме
- **Кастомный тайтлбар** — навигация (назад, вперёд, обновить, домой) и быстрый доступ к настройкам

## Стек технологий

| Компонент | Технология |
|---|---|
| Фреймворк | [Electron](https://www.electronjs.org/) 31 |
| Уведомления | PowerShell + Windows Toast API |
| Реалтайм-события | WebSocket (библиотека `ws`) |
| Хранение настроек | electron-store |
| Сборка | electron-builder (NSIS-установщик + portable) |

## Установка и запуск

### Из исходников

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка дистрибутива (установщик + portable)
npm run dist
```

### Готовый дистрибутив

В разделе [Releases](../../releases) доступны:
- **Adesk Setup.exe** — установщик с выбором директории, ярлыками на рабочем столе и в меню Пуск
- **Adesk.exe** — portable-версия без установки

## Настройки

Панель настроек доступна по кнопке в тайтлбаре. Основные параметры:

| Параметр | Описание |
|---|---|
| API-токен | Токен для подключения к API adesk.ru |
| Домашняя страница | URL, открываемый при запуске |
| Горячая клавиша | Глобальный шорткат для вызова окна |
| Запуск свёрнутым | Запускать приложение скрытым в трей |
| Типы уведомлений | Включение/отключение по категориям (доходы, расходы, плановые платежи, обязательства, низкий баланс) |
| Длительность уведомлений | Время отображения (3с, 5с, 10с, постоянно) |
| Не беспокоить | Подавление уведомлений, когда окно активно |

## Архитектура уведомлений

```
VPS-сервер (webhook) → WebSocket → Notification Service → PowerShell Toast
                                         ↓
                                  Дедупликация событий
                                  Фильтрация по настройкам
                                  Проверка режима "Не беспокоить"
```

При клике на уведомление приложение активируется через протокол `adesk://` и открывает соответствующую страницу.

## Структура проекта

```
├── main.js                      # Главный процесс Electron
├── index.html                   # Основное окно (webview + тайтлбар)
├── preload.js                   # IPC-мост для рендерера
├── settings.html/js/css         # Панель настроек
├── adesk-api.js                 # HTTPS-клиент к API adesk.ru
├── notification-service.js      # Обработка и отправка уведомлений
├── vps-client.js                # WebSocket-клиент
├── powershell-notifications.js  # Нативные Windows toast-уведомления
├── i18n.js                      # Система интернационализации
├── locales/                     # Файлы переводов (en, ru)
└── assets/icons/                # Иконки приложения
```
